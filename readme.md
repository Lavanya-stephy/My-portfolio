# Lavanya Stephy – Portfolio

A responsive, interactive personal portfolio website
for a second-year Cybersecurity engineering student.

## Features

- App-like navigation instead of a long scrolling page
- Responsive sidebar navigation
- Home / About section
- Education timeline
- Categorized technical skills
- LeetCode and HackerRank links
- Interactive project overview and project detail pages
- Certificate carousel
- Event pages
- Extracurricular section
- Contact section
- Keyboard navigation
- Responsive mobile layout
- Reduced-motion accessibility support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Run the Website

1. Download or clone this project.
2. Open the folder in VS Code.
3. Place your images in the corresponding folders.
4. Open index.html in your browser.

For a better development experience, use the Live Server
extension in VS Code.

## Customize

Replace the following placeholders:

- [ADD_LINKEDIN_URL]
- [ADD_HACKERRANK_URL]
- [ADD_BOOKNEST_REPO_LINK]

Replace image placeholders in the assets folder.
